\section{510K Game Rules}

510K is a four-player trick-taking game with a standard 52-card deck.
Cards 5, 10, K carry point values (5, 10, 10).
The lead player sets the pattern (single, pair, straight, bomb, 510K pattern, etc.); others must follow with a higher-rank play or pass.
The trick winner collects all 5/10/K points from the trick.

Four modes share identical card mechanics but differ in team structure and termination:

\begin{itemize}
\item \textsc{Single}: solo-competitive. Game ends when first player empties hand. Winner $+30$, losers $-10$ each.
\item \textsc{Static}: fixed teams (players 0\&2 vs.\ 1\&3). Game ends when both members of one team finish. Winners $+15$, losers $-15$ each.
\item \textsc{Dynamic}: teams by hidden red-Ace distribution (holders of A$\heartsuit$/A$\diamondsuit$ form one team). Scoring same as \textsc{Static}. Red A is the strongest single card; red-A pair is the strongest bomb pattern.
\item \textsc{Obvious}: identical card mechanics to \textsc{Dynamic}, but team membership is observable as a 4-bit teammate indicator. This ablation isolates the effect of information structure while holding card hierarchy constant.
\end{itemize}

\section{Behavioral Features for Path Integral}

Seven mode-independent features ($\phi_1$--$\phi_7$), all with VIF $< 2$ (no multicollinearity):

\begin{itemize}
\item $\phi_1$ \textbf{MyScore}: cumulative 510K points scored by the agent, normalized by 150.
\item $\phi_2$ \textbf{MyHandSize}: fraction of hand already played, $(13 - |h|)/13$.
\item $\phi_3$ \textbf{MyStrength}: average card rank in hand, mapped to $[0,1]$.
\item $\phi_4$ \textbf{TrickScore}: 5/10/K points at stake in the current trick, normalized by 100.
\item $\phi_5$ \textbf{PassCount}: consecutive passes in the current trick, normalized by number of active players.
\item $\phi_6$ \textbf{ScoreSpread}: standard deviation of 510K scores across all players, normalized by 50. (Cooperative feature; measures score inequality.)
\item $\phi_7$ \textbf{SuppressionGap}: when following a trick, rank gap between the player's strongest card and the leader's best card, normalized by 12. $0$ when leading. (Cooperative feature; measures competitive pressure.)
\end{itemize}

\textbf{Feature ablation.}
Deleting any single feature ($\phi_1$--$\phi_7$) preserves the monotonic path-length ordering $\textsc{Single} > \textsc{Static} > \textsc{Dynamic}$ (7/7 subsets), confirming the finding is not an artifact of feature selection.

\section{OBVIOUS Mode Construction}

The \textsc{Obvious} observation vector is 116-dimensional (112 base features + 4 teammate-indicator bits).
Bit $i = 1$ if player $i$ is on the observing agent's team (according to the red-Ace distribution).
This is the only structural difference from \textsc{Dynamic} (112-dim observation), enabling a clean ablation: any difference between DYNAMIC and OBVIOUS is attributable to \textit{team information visibility}, not to card mechanics.
